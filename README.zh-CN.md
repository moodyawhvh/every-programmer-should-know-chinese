## 项目简介

这是每个软件开发者都应该了解的(大部分是)技术类知识合集。这些资源适合任何技术水平、任何技术栈的程序员。清单主观性很强,不保证科学严谨,条目排列也不分先后。

> 译者注:你不需要把这些内容全部背下来才能当程序员,但了解它们会让你变得更强!欢迎向原项目贡献(P.R. 见其 CONTRIBUTING.md)。

- What is Platform Engineering?(Microsoft Learn / Atlassian)— 平台工程概念与团队职责
- Internal Developer Platform (IDP) — 平台团队的核心产品
- Golden Paths(黄金路径)— Spotify 首创,用"有主见的支持路径"引导开发者走向标准工作流

## 使用建议

1. 按章节自上而下浏览,先挑与自己技术栈最相关的主题;
2. 每个条目均保留英文原名,可直接复制到原项目 README 或搜索引擎中定位原文;
3. 建议从"安全""分布式""工程实践"三个章节入手,性价比最高;
4. 学练结合:配合刷题网站章节边学边练。
