## 📖 项目简介

《Every Programmer Should Know》是 GitHub 上一份知名的程序员知识资源清单,收录了每个软件开发者都应该了解的(大部分是)技术类知识。无论你是什么技术水平、用什么技术栈,都能从中找到值得阅读的资料。本仓库提供该清单的中文翻译介绍,并附中文导读文档,方便中文开发者快速定位感兴趣的主题。

## ✨ 主要特性

- **30+ 技术主题一网打尽**:从算法、数据结构到分布式、安全、职业发展全覆盖
- **导论与路线图**:计算机科学地图、开发者学习路线图,帮你建立全局视野
- **常见误区合集(Falsehoods)**:字符串、地址、邮箱、时区与日期等编程"想当然"陷阱
- **经典书目与论文**:涵盖《算法导论》《代码大全》《Clean Code》以及 Papers We Love 等经典资源
- **实战导向**:OWASP Top 10、PortSwigger Academy 等 Web 安全实战靶场直接可练
- **刷题平台索引**:LeetCode、Codeforces、Exercism 等 20+ 编程练习网站
- **职业软实力**:简历优化、面试准备、远程办公、软技能与心理健康资源
- **持续更新的社区项目**:原项目拥有数万 Star,由社区长期维护

## 🚀 快速开始

1. 直接在线阅读:打开 [README.zh-CN.md](README.zh-CN.md) 浏览中文导读
2. 对照英文原版:访问原项目 https://github.com/mtdvio/every-programmer-should-know
3. 如需克隆到本地:

```bash
git clone https://github.com/mtdvio/every-programmer-should-know.git
```

4. 按主题挑选资源:每个章节对应一个技术方向,条目内附原文链接
5. 学以致用:从"刷题网站"和"安全实战"章节入手,边练边学效果最好
